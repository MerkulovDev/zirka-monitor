# 🔌 Zirka Monitor - Моніторинг відключень ДТЕК

Автоматичний моніторинг розкладу відключень електроенергії для адреси **м. Вишгород, вул. Шолуденка, 18А** з повідомленнями в Telegram.

## 📋 Опис

Цей проект автоматично моніторить сайт [ДТЕК Кременчук](https://www.dtek-krem.com.ua/ua/shutdowns) та відправляє сповіщення в Telegram при зміні розкладу відключень електроенергії.

### Особливості

- ✅ Автоматичний обхід захисту Incapsula за допомогою Puppeteer
- ✅ Моніторинг кожну годину через GitHub Actions
- ✅ Миттєві сповіщення в Telegram при змінах
- ✅ Збереження історії змін
- ✅ Детальні логи помилок

## 🚀 Встановлення

### Локально

1. Клонуйте репозиторій:
```bash
git clone https://github.com/MerkulovDev/zirka-monitor.git
cd zirka-monitor
```

2. Встановіть залежності:
```bash
npm install
```

3. Налаштуйте змінні середовища:
```bash
export TELEGRAM_BOT_TOKEN="ваш_токен_бота"
export TELEGRAM_CHAT_ID="ваш_chat_id"
```

4. Запустіть моніторинг:
```bash
npm start
```

### GitHub Actions

Для автоматичного моніторингу через GitHub Actions:

1. Форкніть або клонуйте цей репозиторій
2. Налаштуйте GitHub Secrets в налаштуваннях репозиторію:
   - `Settings` → `Secrets and variables` → `Actions` → `New repository secret`
   - Додайте `TELEGRAM_BOT_TOKEN` з токеном вашого Telegram бота
   - Додайте `TELEGRAM_CHAT_ID` з ID чату або каналу

3. Workflow запускатиметься автоматично кожну годину

## 🤖 Telegram Bot Setup

### Отримання токену бота

1. Створіть бота через [@BotFather](https://t.me/BotFather)
2. Відправте `/newbot` та слідуйте інструкціям
3. Скопіюйте токен (виглядає як `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)

### Отримання Chat ID

#### Для особистих повідомлень:

1. Відправте боту `/start`
2. Відкрийте браузер і перейдіть:
```
https://api.telegram.org/botВАШ_ТОКЕН/getUpdates
```
3. Знайдіть `"chat":{"id":123456789}`
4. Скопіюйте це число

#### Для каналів:

1. Створіть канал або використайте існуючий
2. Додайте бота як адміністратора каналу
3. Отримайте chat_id через:
```
https://api.telegram.org/botВАШ_ТОКЕН/getUpdates
```
4. Для публічних каналів використайте формат: `@ім'я_каналу`
5. Для приватних каналів використайте ID (зазвичай негативне число)

## ⚙️ Налаштування

### Зміна адреси моніторингу

Відредагуйте `monitor.js`:

```javascript
const CONFIG = {
  URL: 'https://www.dtek-krem.com.ua/ua/shutdowns',
  ADDRESS: 'м. Вишгород, вул. Шолуденка, 18А', // Змініть тут
  // ...
};
```

### Зміна частоти моніторингу

Відредагуйте `.github/workflows/dtek-monitor.yml`:

```yaml
schedule:
  - cron: '0 * * * *'  # Кожну годину
  # - cron: '*/30 * * * *'  # Кожні 30 хвилин
  # - cron: '0 */2 * * *'   # Кожні 2 години
```

## 🔍 Як це працює

1. **Запуск браузера**: Puppeteer запускає headless Chrome
2. **Завантаження сторінки**: Перехід на сайт ДТЕК з обходом Incapsula
3. **Пошук розкладу**: Знаходження розкладу для вказаної адреси
4. **Порівняння**: Порівняння з попередньо збереженим розкладом
5. **Сповіщення**: Відправка в Telegram при виявленні змін
6. **Збереження**: Збереження нового розкладу для наступної перевірки

## 🛠️ Розв'язання проблем

### Incapsula блокує доступ

- Скрипт автоматично чекає завантаження контенту
- Можна додати додатковий `waitForTimeout()` при необхідності
- Перевірте, що Puppeteer запускається коректно

### Telegram сповіщення не приходять

1. Перевірте правильність токену бота
2. Перевірте `TELEGRAM_CHAT_ID`
3. Переконайтесь, що бот додано в канал/чат
4. Перегляньте логи в GitHub Actions

### Новий розклад не знаходиться

1. Перевірте, що адреса правильно вказана в `CONFIG.ADDRESS`
2. Перевірте актуальність селекторів на сайті
3. Запустіть скрипт локально для детальних логів

## 📊 GitHub Actions

Workflow можна запустити вручну через вкладку `Actions`:

1. Перейдіть до `Actions` в репозиторії
2. Виберіть workflow `DTEK Power Outage Monitor`
3. Натисніть `Run workflow`
4. Виберіть гілку (`main` / `master`)
5. Натисніть `Run workflow`

## 📅 Графік роботи

За замовчуванням моніторинг запускається **кожну годину**.

Можна змінити через налаштування cron у `.github/workflows/dtek-monitor.yml`.
